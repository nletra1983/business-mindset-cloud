# Quickstart: Короткий разбор автора в Telegram

Проверка среза на уже существующем контуре. Новый контур не поднимается. Запуск: из `/opt/business-mindset` — `docker compose up -d --build bot` (сервис `bot` в compose, без второго процесса).

## Предусловия

- Контейнер на Selectel, каталог `/opt/business-mindset`, Postgres уже есть.
- `TELEGRAM_API_BASE` указывает на CF-прокси.
- Задана `TG_GETBUSINESSIDEA_TOKEN`.
- Ключ DeepSeek: `DEEPSEEK_API_KEY` в `secrets/deepseek.env` (см. [research.md](./research.md)).
- В ходе используется скилл `features/business-idea-from-news/FeatureArtifacts/business-idea-from-news.smoke.md`.

## Сценарии

1. Новый Telegram user id. Ожидание: один внутренний идентификатор и привязка этого id и ника. Повтор с тем же id и другим ником не создаёт второго человека.
2. Пустой ввод. Ожидание: хода нет, есть просьба сформулировать снова.
3. Содержательная формулировка. Ожидание: ход на шаге «событие», формулировка запинена в окне, вопрос события задан.
4. Слабый ответ. Ожидание: шаг тот же, одна фраза о нехватке и повтор вопроса.
5. Достаточные ответы на событие и масштаб. Ожидание: два вопроса по порядку, финал из трёх пунктов, ход завершён, сводка хода записана отдельно от транскрипта. Профиля навыка нет.
6. Тот же update id доставлен дважды. Ожидание: шаг не изменился.
7. Кнопка «к другим вопросам». Ожидание: список незавершённых ходов, прежний ход не завершён, шаг сохранён, короткого следа и статуса «пауза» нет. Сообщение внутри окна до кнопки второй ход не создаёт.
8. Из списка — новая формулировка. Ожидание: прежний ход остаётся не завершён, новый ход со своей запиненной формулировкой.
9. Клик по незавершённому ходу в списке. Ожидание: тот же шаг, те же реплики, та же версия скилла. Следующий ответ за человеком.
10. Вызов модели без ответа, затем успешный повтор. Ожидание: ход продолжается, модель та же.
11. Два обрыва вызова подряд. Ожидание: ход не завершён, статуса «пауза» нет, сообщение о проблемах со связью, предложение продолжить позже.
12. Час недоступности. Ожидание: тренировка прервана, уже принятый ход на месте, офлайн-хода нет.

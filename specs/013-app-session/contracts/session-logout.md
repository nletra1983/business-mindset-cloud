# Contract: сессия на устройстве и logout

## POST `/app/v1/auth/logout`

Заголовок: `Authorization: Bearer <session_secret>`  
Успех: сессия отозвана; дальнейшие вызовы с этим секретом — 401.  
Без секрета или уже отозванный: безопасный исход «снаружи» (не ошибка продукта для человека).

## Устройство

1. После confirm: `put(session_secret)` в secure store.
2. При открытии: если `get()` есть и `/runs` принимает секрет — человек внутри без нового кода.
3. При logout: вызвать `/auth/logout`, затем `clear()`.
4. Ключ модели на устройство не кладётся.

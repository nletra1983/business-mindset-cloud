# Research: сессия и выход

## Decision: отзыв на сервере через уже существующий `app_session`

**Decision**: `POST /app/v1/auth/logout` с Bearer вызывает `sessions.revoke`. Поле `revoked_at` уже в схеме `012`. Idle-timeout не добавляем.

**Rationale**: ADL-021 и граница №3 требуют серверного отзыва. Таблица уже готова.

**Alternatives considered**: Только стереть на телефоне. Отклонено границей. JWT с expiry. Отклонено: сервис сам не выкидывает по таймеру.

## Decision: протокол устройства без Flutter-проекта в этой истории

**Decision**: Модуль `device_session` с операциями put / get / clear. В тестах — память. Реальный secure store подключается, когда появится Flutter-проект (№4).

**Rationale**: №4 явно создаёт Flutter-проект. Дублировать его здесь нельзя. Поведение «секрет в secure store, стереть при выходе» фиксируем протоколом и тестами.

**Alternatives considered**: Создать Flutter сейчас. Отклонено: пересечение с №4. Отложить весь клиентский смысл. Отклонено: спека требует хранение и стирание.

## Decision: повторное открытие = тот же секрет на `/runs`

**Decision**: «Остаться вошедшим» проверяется вызовом списка ходов с сохранённым секретом без нового `/auth/email/*`.

**Rationale**: Вход каналов уже выдаёт секрет; эта история не меняет выдачу.

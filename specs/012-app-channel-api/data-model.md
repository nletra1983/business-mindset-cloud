# Data model: вход каналов

## App session

- Внутренний человек
- Хеш секрета сессии
- Момент выдачи
- Момент отзыва (пусто, пока действует)

Верный код email создаёт сессию. Без действующей сессии действия после входа отклоняются.

## Processed app operation

- Внутренний человек
- Ключ повтора от клиента
- Сохранённый ответ
- Момент записи

Повтор того же ключа возвращает сохранённый ответ и не двигает ход снова.

## Уже существующие

Person, email link, link code, run, settings — без смены смысла. Вход каналов их только вызывает.

# Data model: входы человека

## Person

Внутренний человек. Уже есть. Телефон и Telegram на него только ссылаются.

## Telegram link

Существующая привязка канала. Не меняет смысла: один Telegram — один человек. Без телефона она по-прежнему достаточна для бота.

## Phone link

- Человек
- Номер телефона, один на весь контур
- Подтверждён или ещё нет

Неподтверждённый номер не пускает и не сливает ходы.

## Link code

- Куда выдан: телефон или Telegram
- Адрес: номер или идентификатор Telegram
- Код
- Человек, который запросил привязку
- Момент выдачи

Для одной пары «куда + адрес» хранится один код. Новый код заменяет старый.

## Run

Уже принадлежит человеку. При слиянии меняется только человек. Текст хода, шаг и статус не переписываются.

## Visible profile text

У человека может быть больше одной записи текста «информация о себе». У каждой записи есть источник: текущий вход или присоединённый. Слияние добавляет вторую запись и не правит первую.

## Hidden skill marks

Шесть отметок уже есть у человека. При слиянии каждая отметка сравнивается с той же отметкой второго входа. Различаются — становится «неравномерно». Совпадают — остаётся. Свидетельства переходят вместе с ходами и не пересказываются.

## Profile edit session

Сессия редактирования текста остаётся у человека, который подтвердил. Сессия второго входа снимается, чтобы два вопроса не шли сразу.

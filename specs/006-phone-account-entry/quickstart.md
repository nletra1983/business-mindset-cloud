# Quickstart: вход с телефона

Проверка истории аккаунта. Приложение Android не запускается. Второй бот не запускается.

## Предусловие

Из корня репозитория, Python 3.12:

```text
py -3.12 -m pytest tests/test_phone_entrances.py tests/test_account_settings_entry.py tests/test_self_info_profile.py
```

Отправка SMS в этих тестах ничего не шлёт наружу. Код читается из подменённой отправки.

## Что должно пройти

1. Новый номер и верный код пускают без Telegram. Неверный код не пускает.
2. Текст SMS не содержит реплики упражнения.
3. Человек только из Telegram продолжает ход, телефон не спрашивается.
4. В настройках бота номер без верного кода не сливает ходы.
5. После верного кода ходы обоих входов у одного человека. Разные отметки навыка — «неравномерно». Два текста профиля остаются двумя текстами.
6. Номер, уже подтверждённый у человека, нельзя подтвердить второму человеку отдельно от слияния.

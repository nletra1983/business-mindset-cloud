# Contract: вход в настройки аккаунта из клавиатуры разбора

Нового публичного HTTP API не добавляется. Контракт описывает пользовательский Telegram-поток и callback-поведение.

## Entry button

- В сообщениях, где раньше был прямой вход к выбору модели, доступна кнопка `настройки`.
- Контексты присутствия:
  - незавершённый ход;
  - список ходов;
  - после финала.

## First-level settings menu

После нажатия `настройки` пользователь получает меню первого уровня с двумя пунктами:

1. `выбор модели`
2. `информация о себе`

## Routing rules

- Выбор `выбор модели` открывает уже существующий поток model-switch без изменения его бизнес-правил.
- Выбор `информация о себе` переводит пользователя в entry-point истории профиля (детализация самой истории вне этого контракта).

## State safety rules

- Открытие меню `настройки` не изменяет:
  - шаг текущего хода;
  - статус текущего хода;
  - историю реплик.
- Нажатие `настройки` не создаёт новый ход.

## Unsupported/stale interaction handling

- Если callback `настройки` пришёл из неподдерживаемого или устаревшего контекста, система возвращает восстановимое пользовательское сообщение.
- При таком событии состояние хода не изменяется.

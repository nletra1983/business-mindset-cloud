# Quickstart: вход в настройки из клавиатуры разбора

Проверка выполняется на существующем Telegram-контуре без нового сервиса.

## Preconditions

- Бот запущен в текущем рабочем окружении.
- Доступен пользователь с хотя бы одним активным сценарием разбора.
- Выбор модели из истории `002-telegram-model-switch` уже работает.

## Validation scenarios

1. Открой незавершённый ход.
2. Проверь, что на клавиатуре есть кнопка `настройки`.
3. Нажми `настройки`.
4. Убедись, что открылось меню с двумя пунктами:
   - `выбор модели`
   - `информация о себе`

Ожидание: меню открывается и содержит ровно два пункта.

5. Повтори шаги 1-4 из контекста списка ходов.
6. Повтори шаги 1-4 из контекста после финального сообщения разбора.

Ожидание: вход в настройки доступен во всех трёх контекстах.

7. Из меню настроек выбери `выбор модели`.

Ожидание: запускается существующий поток выбора модели, его поведение не меняется.

8. Вернись в незавершённый ход после открытия настроек.

Ожидание: шаг хода, статус хода и уже записанные реплики не изменились.

9. Отправь/смоделируй повторное устаревшее нажатие `настройки` (stale callback).

Ожидание: пользователь получает восстановимое сообщение, состояние хода не портится.

## Pass criteria

- Все три контекста дают вход в настройки.
- Меню настроек всегда содержит оба пункта первого уровня.
- Нет регрессии в потоке выбора модели.
- Нет побочного изменения состояния хода от самого факта открытия настроек.

# Quickstart: экран входа по email

Приложение на телефон не ставится. Проверяется ответ, который этот экран показывает.

```text
py -3.12 -m pytest tests/test_app_email_entry.py tests/test_email_entrances.py
```

## Что должно пройти

1. Верный код пускает и не упоминает Telegram.
2. Неверный код не показывает список и не создаёт второго человека.
3. В списке только ходы этого входа. Чужой ход отсутствует.
4. Пустой список всё равно означает, что человек внутри.
5. У списка нет действий открыть ход, начать разбор, открыть настройки или добавить Telegram.

# Quickstart: `информация о себе` из настроек

Проверка проводится на существующем Telegram-контуре без нового сервиса.

## Preconditions

- История `003-open-settings-from-keyboard` уже внедрена (кнопка `настройки` работает).
- Бот запущен в текущем окружении.
- У тестового пользователя есть доступ к меню `настройки`.

## Validation scenarios

1. Открой `настройки` и нажми `информация о себе`.

Ожидание: бот показывает текущий user-visible профиль (сильные, слабые, факты) без hidden evaluator полей.

2. Введи новый текст для сильных сторон.

Ожидание: бот принимает значение и переходит к вопросу о слабых сторонах.

3. Введи новый текст для слабых сторон.

Ожидание: бот принимает значение и предлагает добавить дополнительный факт о себе.

4. Добавь новый факт о себе.

Ожидание: факт сохраняется в видимом профиле.

5. Повтори вход в `информация о себе`.

Ожидание: виден обновлённый текст сильных/слабых сторон и добавленный факт.

6. Отправь пустой (или только пробелы) ответ на шаге редактирования.

Ожидание: recoverable-подсказка, предыдущее валидное значение не потеряно.

7. Смоделируй stale/unsupported callback в профильном потоке.

Ожидание: recoverable-ответ, persisted данные профиля не меняются.

## Pass criteria

- Вход в `информация о себе` работает из `настройки`.
- User-visible профиль читается и редактируется по шагам.
- Пустой ввод не затирает сохранённые значения.
- Hidden evaluator профиль не раскрывается и не перезаписывается прямыми правками.

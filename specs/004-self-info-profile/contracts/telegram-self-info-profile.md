# Contract: Telegram поток `информация о себе`

Нового публичного HTTP API не добавляется. Контракт описывает Telegram callback/message поведение в рамках существующего бота.

## Entry point

- В меню `настройки` доступен пункт `информация о себе` с callback `settings:profile`.
- Нажатие `settings:profile` открывает профильный сценарий для текущего человека.

## Read behavior

- При входе в `информация о себе` бот отправляет user-visible профиль:
  - сильные стороны,
  - слабые стороны,
  - факты о себе (сказано человеком).
- Ответ MUST NOT содержать hidden evaluator статусы и внутренние ids характеристик.

## Edit behavior

- Бот отдельно спрашивает:
  1. сильные стороны;
  2. слабые стороны;
  3. дополнительный факт о себе (опционально).
- Валидный ввод сохраняется в visible-профиль и доступен при следующем чтении.
- Пустой/пробельный ввод возвращает recoverable-подсказку и не стирает сохранённые значения.

## Privacy and separation rules

- Правки через `информация о себе` меняют только visible-профиль.
- Hidden evaluator профиль не показывается пользователю.
- Правки visible-профиля не обновляют evaluator-статусы hidden-профиля.

## Stale/unsupported handling

- Для устаревших/неподдерживаемых callback/message в профильном потоке бот возвращает recoverable сообщение.
- На таком событии persisted профильные данные не меняются.

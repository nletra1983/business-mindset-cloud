# Quickstart: вход по email

Проверка правил аккаунта. Приложение Android не запускается. Второй бот не запускается. Кнопки настроек этой историей не добавляются.

## Предусловие

Из корня репозитория, Python 3.12:

```text
py -3.12 -m pytest tests/test_email_entrances.py tests/test_phone_entrances.py tests/test_account_settings_entry.py
```

Письмо в этих тестах ничего не шлёт наружу. Код читается из подменённой отправки.

## Что должно пройти

1. Новый email и верный код пускают без Telegram. Неверный и заменённый код не пускают и не создают второго человека.
2. Уже подтверждённый email открывает того же человека и не сливает чужие ходы.
3. Текст письма не содержит реплики упражнения.
4. Человек только из Telegram продолжает ход, email не спрашивается.
5. Один код из двух указанных входов не сливает ходы.
6. После обоих кодов ходы обоих входов у одного человека. Разные отметки навыка — «неравномерно». Два текста профиля остаются двумя текстами.

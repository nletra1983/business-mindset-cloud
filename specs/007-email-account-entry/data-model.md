# Data model: входы человека

## Person

Внутренний человек. Уже есть. Email и Telegram на него только ссылаются.

## Telegram link

Существующая привязка канала. Один Telegram — один человек. Без email она достаточна для бота.

## Email link

- Человек
- Адрес email, один на весь контур
- Подтверждён или ещё нет

Неподтверждённый адрес не пускает и не сливает ходы.

## Link code

- Куда выдан: email или Telegram
- Адрес: почта или идентификатор Telegram
- Код
- Зачем выдан: вход или настройка
- Человек, который запросил привязку, если это настройка
- Момент выдачи

Для одной пары «куда + адрес» хранится один код. Новый код заменяет старый.

## Staged link

Значение, которое уже указали, но ещё не подтвердили. Пока хотя бы одно указанное значение не подтверждено, ходы не сливаются.

## Run

Уже принадлежит человеку. При слиянии меняется только человек. Текст хода, шаг и статус не переписываются.

## Visible profile text

У человека может быть больше одной записи текста «информация о себе». Слияние добавляет вторую запись и не правит первую.

## Hidden skill marks

Шесть отметок уже есть у человека. При слиянии каждая отметка сравнивается с той же отметкой второго входа. Различаются — становится «неравномерно». Совпадают — остаётся. Свидетельства переходят вместе с ходами.

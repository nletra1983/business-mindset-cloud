# Contract: смена модели в Telegram

Нового публичного HTTP API нет. Наружу — те же сообщения бота. Вызов модели делает только сервер.

Вызовы делает только сервер. DeepSeek: `POST https://api.deepseek.com/chat/completions`, модель `deepseek-chat`. GigaChat: сначала `POST https://ngw.devices.sberbank.ru:9443/api/v2/oauth` со scope `GIGACHAT_API_PERS`, затем `POST https://api.giga.chat/v1/chat/completions`, модель `GigaChat-2`. GLM: `POST https://api.z.ai/api/paas/v4/chat/completions`, модель `glm-5.3-flash`. Подробности — в [research.md](../research.md). Значения ключей в контракт не входят.

## Клавиатура

На каждом сообщении бота, где уже есть «к другим вопросам», рядом есть кнопка, которая открывает список моделей. Текст этой кнопки — имя текущей модели: DeepSeek, GigaChat или GLM. Пока человек не выбирал, это DeepSeek. После выбора и после автоматического возврата подпись становится именем той модели, которая стала текущей.

Нажатие этой кнопки присылает сообщение со тремя кнопками, сверху вниз:

1. DeepSeek — id `deepseek-chat`
2. GigaChat — id `GigaChat-2`
3. GLM — id `glm-5.3-flash`

Текущая модель — зелёная кнопка (стиль `success`). Две остальные без стиля. Текст кнопок не делается жирным. Отдельная фраза с именем не требуется.

Нажатие имени делает эту модель текущей и обновляет отметку. То же сообщение становится текстом «Модель изменена.» без кнопок. Список и приглашение «Выбери модель.» повторно не показываются. Нового хода это нажатие не создаёт. Имя текстом и отдельная команда не принимаются.

Пока бот ещё не прислал сообщение с клавиатурой, этой кнопки нет.

## Когда выбор действует

- В незавершённом ходе следующий вопрос, оценка ответа и финал идут текущей моделью.
- В списке ходов и после финала выбор запоминается за человеком. Завершённый ход не переписывается.
- Пока человек не нажимал модель, текущая — DeepSeek.

## Недоступность

Тот же вызов повторяется один раз. Если повтор тоже не вернулся:

- текст сообщения говорит, что выбранная модель недоступна;
- в этом же сообщении снова три кнопки;
- ход не завершается и не становится паузой;
- если какая-то модель уже отвечала, отметка стоит на ней;
- если не отвечала ни одна, отметка остаётся на той, что была текущей, и другая модель не подставляется.

Повтор того же update id не меняет текущую модель второй раз.

## Секреты

В контейнер `bot` читаются уже лежащие на сервере `secrets/deepseek.env`, `secrets/sber.env`, `secrets/zai.env`. В контракт входят только имена переменных: `DEEPSEEK_API_KEY`, `GIGACHAT_AUTH_KEY`, `ZAI_API_KEY`. Значения не записываются.

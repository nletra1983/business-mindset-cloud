# Quickstart: Переключение модели в разборе

Проверка на уже работающем контуре. Новый контур не поднимается. Запуск после выкладки: из `/opt/business-mindset` — `docker compose up -d --build bot`. Второй процесс бота не запускать.

Протоколы трёх моделей записаны в [research.md](./research.md). GigaChat пока вызывается как физлицо.

## Предусловия

- Тот же контейнер и Postgres, что уже обслуживают короткий разбор.
- `TELEGRAM_API_BASE` указывает на CF-прокси.
- Задана `TG_GETBUSINESSIDEA_TOKEN`.
- Ключи на месте: `DEEPSEEK_API_KEY`, `GIGACHAT_AUTH_KEY`, `ZAI_API_KEY`. Значения в этот файл не писать.
- Скилл хода по-прежнему `business-idea-from-news.smoke`.

## Сценарии

1. Сообщение бота в незавершённом ходе. Ожидание: рядом с «к другим вопросам» кнопка с именем текущей модели. Пока выбора не было — DeepSeek.
2. Нажатие этой кнопки. Ожидание: три кнопки, DeepSeek, GigaChat, GLM. Текущая зелёная, две остальные обычные. Отдельной фразы с именем нет. Следующее сообщение бота с «к другим вопросам» подписывает кнопку уже выбранным именем.
3. Нажатие другого имени в незавершённом ходе. Ожидание: то же сообщение становится «Модель изменена.» и без кнопок. Список повторно не показывается. Уже данные ответы на месте, второй ход не создан. Следующий вопрос или оценка идут этой моделью.
4. Достаточный путь до финала на каждой из трёх моделей. Ожидание: 3 из 3, следующий ответ того хода идёт выбранной моделью.
5. Выбранная модель не отвечает, повтор того же вызова тоже не отвечает, и раньше отвечала другая. Ожидание: одно сообщение о недоступности, в нём три кнопки, зелёная кнопка у предыдущей ответившей, ход не завершён, паузы нет.
6. Ни одна модель ещё не отвечала, и выбранная дважды не ответила. Ожидание: сообщение о недоступности, три кнопки, другая модель не подставлена, ход не завершён.
7. Смена модели после финала. Ожидание: выбор помнится, уже записанные ответы и финал того хода не изменились. Следующий новый ход зовёт новую модель.
8. Повтор того же нажатия (тот же update id). Ожидание: модель не переключается второй раз.

# Граница истории №2: гостевой тренажёр — 3 шага smoke

Зависит от №0.

## Входит

Гость без email: новость из get-news (или свой факт); форма → лента; до 3 шагов `business-idea-from-news.smoke`; индикатор ожидания; «очистить» (UI); лимит ≤3 окон/день на cookie; после 3-го шага — показ гейта (сам гейт email — №3). SmartCaptcha перед вызовом модели.

## Не входит

Email, шаги 4–6, оплата, письмо дня 2, полные маркетинговые блоки (№1).

## Открытые дыры

Нет.

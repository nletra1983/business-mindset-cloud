# Граница истории №1: лендинг — hero и блоки страницы

Зависит от №0 (страницы отдаются с того же хоста).

## Входит

Структура страницы по `business-logic.md`: hero с одной CTA «без регистрации», блоки «как работает», не ChatGPT, что получаете, уровни доступа (с ориентиром суммы по умолчанию 100 ₽), живой пример без фейковых отзывов, для кого, место под автора, FAQ + дисклеймер, финальный CTA. Мобильный приоритет. Русский. Каркас демо-зоны (якорь/место под тренажёр №2).

## Не входит

Логика smoke, get-news, email-гейт, оплата, капча, письмо дня 2. Финальные маркетинговые тексты автора, если их ещё нет — заглушки смысла без искажения скиллов.

# История: войти в приложение по email и работать без Telegram

Граница этой истории. Правила аккаунта лежат в `features/mobile-app/arch-change.md` и здесь не меняются.

## Что видит человек

Человек открывает приложение, указывает email и код из письма. Telegram не предлагается и не требуется. После верного кода он видит список своих ходов. Список может быть пустым.

Пока этот вход не слит с другим, в списке только ходы этого входа.

Открыть ход, начать разбор, открыть настройки и указать второй вход эта история не даёт. Это следующие истории.

## Что не меняется

Неверный или уже заменённый код не пускает и не создаёт второго человека. Письмо содержит только код. Приложение не вызывает модели. Офлайн-хода нет. Первая сборка — Android для автора, без магазинов. iOS позже пользуется теми же правилами входа.

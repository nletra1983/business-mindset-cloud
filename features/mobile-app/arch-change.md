# Задание: вход с телефона и необязательный Telegram

Решение принято 2026-10-28, пометка `ARH-CHANGE` снята. Это задание на внедрение в уже работающий продукт, не правка старых спек.

## Что меняется в уже работающем продукте

Сейчас человек появляется только из Telegram. Нужно, чтобы человек мог появиться из телефона и работать в приложении без бота. Бот при этом остаётся как есть: им можно пользоваться без телефона.

Телефон и Telegram — привязки к уже существующему внутреннему идентификатору, не два разных ключа человека. Слияние не происходит само при входе. Оно происходит в настройках, когда человек указал оба входа. Телефон подтверждается кодом по SMS, Telegram — кодом в боте.

При слиянии ходы обоих входов остаются. Если отметки одного навыка различаются, ставится «неравномерно». Если совпадают, отметка не меняется. Текст профиля эта задача не склеивает: это отдельный бэклог скилла.

Код SMS уходит с сервера во внешнюю отправку. Текст диалога туда не передаётся. Провайдера SMS эта задача не выбирает.

Приложение ходит только в модуль каналов. Ядро остаётся одним процессом. Подпись модуля «Аккаунт» на схеме контейнеров уже приведена к этому решению.

## Конституция

Правка не нужна. Внутренний идентификатор остаётся ключом человека. Telegram по-прежнему не ключ. Телефон становится второй такой же привязкой. Первый канал продукта по-прежнему Telegram. Это не отдельный продукт и не второй процесс.

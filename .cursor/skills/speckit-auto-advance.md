# Автопереход Spec Kit (Business Mindset)

Правило для `/speckit-specify`, `/speckit-plan`, `/speckit-tasks`, `/speckit-implement`. Цель: не срезать углы скиллов, но не ждать человека после каждого зелёного шага **до tasks**.

## Цепочка одной истории

Порядок артефактов: **specify → plan → tasks → implement**.  
Автопереход по умолчанию только: **specify → plan → tasks**. Дальше стоп.

После успешного завершения шага:

1. Если есть вопрос человеку, `[NEEDS CLARIFICATION: …]`, проваленный gate `/check-ready-to-speckit`, конфликт конституции или неоднозначный вход — **остановиться**. Следующий шаг не начинать.
2. Если шаг был **specify** или **plan** и пункта 1 нет — **сразу** следующий скилл той же спеки (`plan` / `tasks`).
3. Если шаг был **tasks** и пункта 1 нет — **остановиться**. Кратко сказать, что `tasks.md` готов, и что дальше явно: `/speckit-implement`, отдельно `/publish`.
4. Перед каждым шагом читать и соблюдать полный `SKILL.md` этого шага. Автопереход не освобождает от скилла и не склеивает два шага в один «укороченный».
5. Две истории в один specify / один plan / одни tasks / один implement — **запрещены**.

`implement` и `/publish` **не** входят в автопереход. Их запускает только человек отдельными командами.

Оговорка на один заход: если в том же сообщении написано «и сразу implement» / «без остановки перед implement» — после зелёных tasks можно перейти к `/speckit-implement` этой же спеки. `/publish` всё равно только по явной команде.

## Несколько историй подряд

Если человек назвал несколько историй (номера, названия) или сказал полный поток по списку ready:

- для каждой: довести автоцепочку до **tasks** (или стоп по вопросу);
- коротко написать в чат, какая история доведена до tasks;
- перейти к следующей с `/speckit-specify` (с gate штампа) **без** ожидания «можно следующую», если список уже дан;
- **не** запускать implement и **не** `/publish` между историями;
- если список не дан — после tasks одной истории остановиться.

## Что не считается «нет вопросов»

- Молчание человека в чате, пока агент ещё не завершил шаг.
- Догадка вместо дыры в границе или спеке.
- «Похоже понятно» при маркере `NEEDS CLARIFICATION` или красном stamp.

## Зачем так

Implement и публикация дороже по токенам и необратимее (код, сервер, APK). Автоматизация копит постановку и tasks; реализацию и выкладку человек включает сам, когда готов.

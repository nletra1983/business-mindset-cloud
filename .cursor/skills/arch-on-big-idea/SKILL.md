# Architecture from a big idea

Команда `/arch-on-big-idea`. Текст после команды — вход. Без этого текста не начинай: попроси идею и остановись.

Методика лежит в [it-solution-architect](../it-solution-architect/SKILL.md). Прочитай её и иди по разделу «Порядок работы». Шаги, вопросы и состав файлов не заменяй своим списком.

Список команд проекта — [commands.md](../../../commands.md). Если в этом заходе появляется новая команда после `/`, добавь туда строку.

Как читать вход:

- Если верхний уровень по этой идее ещё не начат, вход — исходные слова идеи. Запиши их до пересказа.
- Если вопросы уже заданы, а решений в `ProductLC/01 Big Idea/architecture/arch-decision-log.md` по ним нет, вход — ответы. Допиши решения и только потом переходи к схемам.
- Не рисуй схемы в том же заходе, где впервые задаёшь вопросы.

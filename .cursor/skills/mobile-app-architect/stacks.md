# Клиенты, октябрь 2026

Перед тем как записать версию в проект, открыть первоисточник. Ниже — ориентир на 2026-10-29, не вечный пин.

## Нативный Android

Kotlin и Jetpack Compose. Новый интерфейс на XML Views не начинать. Compose BOM на эту дату — линейка `2026.09`; Compose 1.12 требует `compileSdk` 37 и Android Gradle Plugin 9.1+.

Google Play с 31 августа 2026 принимает новые приложения и обновления с target API 36 (Android 16) или выше. Файл автору в обход магазина этим порогом не связан, но target держать современным, чтобы переход в магазин не стал переписыванием.

Сборка APK идёт на Windows. Магазинный формат — AAB, не файл для ручной установки.

## Нативный iOS

Swift и SwiftUI. UIKit — только точечно, где SwiftUI ещё не закрывает системный жест.

С 28 апреля 2026 загрузка в App Store Connect требует Xcode 26 или новее и SDK iOS 26. Минимальная версия iOS у самого приложения может быть ниже: с 9 сентября 2026 загрузка требует цель от iOS 13. Свежий Xcode 27 уже существует; перед сборкой взять тот, который Apple сейчас принимает.

Собрать и подписать iOS можно только на Mac либо на арендованном macOS. Windows автора для iOS-файла недостаточен. Аккаунт Apple Developer нужен для установки на свой iPhone не через симулятор и для TestFlight.

## Универсальные

Три живых пути. Остальное (Ionic, Capacitor, .NET MAUI) для этого продукта не предлагать: диалог с сервером не выигрывает от обёртки над сайтом, а второй стек без команды его не окупает.

| Путь | Когда он уместен | Цена |
|---|---|---|
| Flutter, stable 3.47 и новее, рендер Impeller | Один интерфейс на обе ОС, мало платформенных датчиков, APK нужен с Windows | Свой рисунок интерфейса. iOS всё равно собирается на Mac. Для Android, Windows и Linux брать не старее 3.47.8: там закрыт компрометированный промежуточный сертификат |
| React Native, New Architecture по умолчанию (Fabric, TurboModules, Hermes), обычно через Expo | Команда уже пишет на TypeScript и React | Мост к редкому системному API. iOS на Mac |
| Kotlin Multiplatform | Общая логика на Kotlin, интерфейс нативный: Compose на Android и SwiftUI на iOS | Два интерфейса. Имеет смысл, когда нативные ощущения важнее скорости одного человека |
| Compose Multiplatform | Общий интерфейс на Compose, включая iOS | Моложе Flutter на жестах iOS. Брать, если Kotlin уже выбран и второй язык не нужен |

Два полностью отдельных приложения (Kotlin и Swift) — когда платформенные API составляют сам продукт: камера, сложные жесты, виджеты с первого дня. Для диалога, списка и настроек это двойная работа без выигрыша.

## Что остаётся платформенным в любом клиенте

- Сессионный секрет: Android Keystore и iOS Keychain. Ключ провайдера модели на телефон не класть.
- Сеть только к своему серверу. Провайдера модели вызывает сервер.
- Разрешения спрашивать в момент действия. Для первой сборки этого продукта камера, геолокация и пуши не нужны, пока история их не потребует.
- Подпись и идентификатор пакета живут у платформы. Смена идентификатора — новое приложение на телефоне.

## Умолчание для этого репозитория

Пока человек не выбрал иное: Flutter последней stable. Android-файл собирается на Windows. iOS — второй шаг на Mac, те же правила входа и хода. Запись в журнал решений — только после согласия человека.

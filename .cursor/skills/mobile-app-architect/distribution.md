# Установка

## Файл автору, Android

Первая сборка этого продукта — Android, только автор, без магазинов. На телефон попадает подписанный APK.

- Подпись — свой ключ, который хранится у автора вне git. Следующая версия ставится поверх только с тем же ключом. Потеря ключа означает новое приложение и новую установку.
- AAB для этой установки не нужен. AAB принимает магазин, телефон из него сам не ставится.
- Передача: файл на телефон. Телефон один раз разрешает установку из этого источника.
- Обновление: новый APK с той же подписью и тем же идентификатором пакета, версия выше предыдущей.

Аккаунт разработчика, карточка магазина, скриншоты и модерация для этого файла не требуются.

## iOS для автора

Файл для своего iPhone собирается на Mac и ставится через Xcode либо через TestFlight. TestFlight и установка мимо симулятора требуют аккаунта Apple Developer. На Windows этот файл не появляется.

## Когда приложение ставят другие люди

Отдельное решение, не часть первой сборки.

- Google Play — target API по правилу Play на дату загрузки, формат AAB, аккаунт разработчика.
- RuStore — уместный путь для людей в РФ, если Google Play неудобен. Свои правила подписи и карточки, их читать на дату публикации.
- App Store — Xcode и SDK по правилу Apple на дату загрузки, ревью, аккаунт Apple.
- Рассылка APK остаётся запасным путём для Android и не заменяет магазин, когда пользователей больше одного автора.

Оплата внутри приложения и правила магазина на комиссию подключаются вместе с фичей оплаты, не вместе с первым APK.

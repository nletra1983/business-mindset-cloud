# Срез: профиль навыка

Дата: 2026-10-28  
Статус: граница названа человеком

## Имя среза (для Spec Kit)

`telegram-skill-profile`

## Зачем этот срез

Хранить информацию о человеке в двух файлах. Один человек может прочитать, изменить и дополнить. Второй агент пишет сам по скиллу и человеку не показывает. Вход к своему файлу и к уже сделанному выбору модели — кнопка «настройки».

## Входит

1. На клавиатуре, где сейчас стоит имя модели, вместо неё кнопка «настройки». Она есть в те же моменты, когда имя модели было на клавиатуре: незавершённый ход, список ходов, после финала.
2. «Настройки» открывают два пункта этого среза: выбор модели и «информация о себе».
3. Выбор модели остаётся тем, что уже работает. Меняется только место входа: из настроек, не с клавиатуры разбора. Три имени, текущая зелёная, после выбора сообщение «Модель изменена.» без кнопок. Правила недоступности модели не меняются.
4. «Информация о себе» — файл, который можно показать. В нём только слова человека: сильные стороны, слабые стороны и другие факты о себе, которые он сам назвал. Оценок агента в этом файле нет.
5. По кнопке «информация о себе» человек читает то, что уже записано. Агент отдельно спрашивает сильные стороны и отдельно слабые. Человек может изменить записанное и добавить новое.
6. Второй файл человеку не показывается. Его пишет агент по скиллу профиля для тренировки. Поля: замечать возможность; держать разные ответы; отличать то, за что платят; действовать при неполных данных; опираться на то, что уже есть; учиться на проверке; «сейчас тренировать». «Сейчас тренировать» — выбор одной характеристики из шести, не седьмая характеристика.
7. По каждому из шести полей агент хранит статус и свидетельство: цитату, задание и ход. Статусы: не наблюдалось, проявляется, слабо, устойчиво, неравномерно. Пустая графа не слабость. Один ход не ставит «устойчиво». Правка файла «информация о себе» статус характеристики не меняет.
8. Короткий разбор «событие и масштаб» может обновить только «замечать возможность». Остальные пять полей остаются «не наблюдалось», пока задание не даёт по ним свидетельство.

## Не входит

- Подключение платных моделей. Место в настройках для него будет отдельной фичей.
- Карточка прошлого разбора, повтор темы, скрытый показ оценок человеку, удаление разбора. Это отложено до мобильного приложения.
- Анкета про биографию, деньги и контакты. Агент их не выспрашивает и не додумывает.
- Новый провайдер модели и смена стека.

## Опора

- `features/account-settings/business-logic.md` — логика фичи, из которой нарезан этот срез.
- `features/business-idea-from-news/FeatureArtifacts/user-profile-mindset.md` — тот же профиль навыка: шаблон, шесть характеристик, правила слияния.
- `features/business-idea-from-news/FeatureArtifacts/business-idea-from-news.md` — какие свидетельства полный разбор отдаёт в профиль.
- `features/business-idea-from-news/FeatureArtifacts/business-idea-from-news.smoke.md` — текущий короткий разбор; сводку навыка сам не пишет.
- `ProductArtifacts/model-switch-slice.md` — выбор модели, который этот срез переносит в настройки и не переписывает.
- `.specify/memory/constitution.md` — стек не перевыбирается.

# Команды проекта

| Команда | Скилл | Зачем |
|---|---|---|
| `/arch-on-big-idea` | `.cursor/skills/arch-on-big-idea/` | Верхнеуровневая архитектура большой идеи |
| `/po-new-feature` | `.cursor/skills/po-new-feature/` | Новая фича: постановка и черновые истории |
| `/arch-new-feature` | `.cursor/skills/arch-new-feature/` | Проверка фичи против архитектуры |
| `/po-new-story` | `.cursor/skills/po-new-story/` | Дописать дыры и поставить `ready-for-speckit` |
| `/check-ready-to-speckit` | `.cursor/skills/check-ready-to-speckit/` | Проверить фичу или истории перед Spec Kit по артефактам; дописать из чата; иначе спросить; пишет штамп |
| `/speckit-specify` | `.cursor/skills/speckit-specify/` | Спека одной истории; сначала свежий штамп `/check-ready-to-speckit` |
| `/speckit-plan` | `.cursor/skills/speckit-plan/` | План реализации спеки |
| `/speckit-tasks` | `.cursor/skills/speckit-tasks/` | Задачи по плану |
| `/speckit-implement` | `.cursor/skills/speckit-implement/` | Реализация задач |
| `/speckit-clarify` | `.cursor/skills/speckit-clarify/` | Уточнения внутри спеки |
| `/speckit-analyze` | `.cursor/skills/speckit-analyze/` | Анализ согласованности артефактов Spec Kit |
| `/speckit-checklist` | `.cursor/skills/speckit-checklist/` | Чеклист по фиче |
| `/speckit-converge` | `.cursor/skills/speckit-converge/` | Схождение остатка работ в tasks |
| `/speckit-constitution` | `.cursor/skills/speckit-constitution/` | Конституция |

Новая фича: `/po-new-feature` → `/arch-new-feature` → `/po-new-story` → при необходимости `/check-ready-to-speckit` → `/speckit-specify` по одной истории.
